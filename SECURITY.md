# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen gibt es nur für die jeweils aktuelle Version (derzeit **2.5.x**).

## Sicherheitslücke melden

Bitte **keine öffentlichen Issues** für Sicherheitsprobleme.

- Bevorzugt: GitHub-Funktion „Report a vulnerability“ im Reiter *Security* des Repositories (Private Vulnerability Reporting).
- Alternativ: E-Mail an ma.poenisch@gmail.com mit Betreff „SECURITY LeadPilot“.

Bitte angeben: betroffene Version, Beschreibung, Schritte zur Reproduktion, mögliche Auswirkung. Keine echten Zugangsdaten oder personenbezogenen Daten mitschicken.

Erste Rückmeldung in der Regel innerhalb von 7 Tagen. Das Projekt wird in der Freizeit betreut; feste Fristen für Korrekturen gibt es nicht.

## Hinweise

- Das Projekt ist ein Demo-/Portfolioprojekt mit fiktiven Daten des Unternehmens LeadPilot.
- Secrets und Schlüssel gehören nie ins Repository (`.env` ist ausgeschlossen).
