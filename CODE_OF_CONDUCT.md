# Verhaltenskodex

Dieses Projekt ist ein persönliches Lern- und Portfolioprojekt. Wer sich hier beteiligt (Issues, Pull Requests, Kommentare), hält sich an diese Regeln:

- Respektvoller, sachlicher Umgang. Kritik bezieht sich auf Code und Ergebnisse, nicht auf Personen.
- Keine Beleidigungen, Diskriminierung, Belästigung oder persönlichen Angriffe.
- Keine fremden persönlichen Daten veröffentlichen.
- Konstruktiv bleiben: Probleme beschreiben, Lösungen vorschlagen.

Verstöße kann der Projektinhaber verwarnen, Beiträge entfernen und Personen vom Projekt ausschließen.

**Meldung:** per E-Mail an ma.poenisch@gmail.com oder über einen privaten Hinweis auf GitHub.

Dieser Kodex orientiert sich am [Contributor Covenant](https://www.contributor-covenant.org/de/version/2/1/code_of_conduct/).
