## Bewusster Future Scope (nicht in V1.1)

- Dedizierter Command Layer (`CommandBus`, Entscheidungen 1574–1584) — Nachvoll­zieh­barkeit läuft in V1.x über `correlationId`.
- Reale Datenquellen-Konnektoren (`HubSpotSource`, `SalesforceSource`, `PostgresSource`) — Drop-in über das `DataSource`-Interface, je eigener Auftrag.
- `CompositeDataSource` (Merge mehrerer Quellen), echter `LiveFeed` (Ebene C).
- Parameter-Erweiterungen außerhalb der 10-Feld-V1-Surface (Kanalbudgets einzeln, Ramp-ups, Lead-Expiration, Setup-Fees, Paketpreise) — je eigener Auftrag mit Registry-Eintrag + Validierung + UI + Test.
- PDF/CSV-Export von Szenariovergleichen.
- Schema-Migration für inkompatible `schemaVersion`.
