## Errungenschaften der Härtungsphasen (G29 – G42)

In den Gates G29 bis G42 wurden substantielle Härtungsschritte im Repository vollzogen:
- **Repo-Hygiene (G29):** Migration in frisches Repo `v2`, Bereinigung von Build-Tools.
- **Linter & Tooling (G30–G31):** ESLint Flat Config, Prettier, Vitest, Testing Library, Playwright E2E-Suite, CI-Pipeline.
- **Architektur & State-Management (G32–G37):** Umstellung der Live-Hooks auf `useSyncExternalStore` (G33), Single-Realtime-Channel-Multiplexing (G34), Beseitigung aller Layering-Verstöße (G35), TanStack Query für Server-State (G36), Zustand-Store für Simulation (G37).
- **Design-System & Styling (G38–G39):** Design-Token-Fundament, schrittweise Bereinigung von ~1.400 statischen Inline-Styles auf Tailwind-Utilities.
- **Rendering & Performance (G40–G41):** Aufteilung monolithischer Komponenten (G40), Code-Splitting in Chunks (`recharts-vendor`, `supabase-vendor`, `framer-motion-vendor`), Entblockung von Web-Fonts, Initial-Bundle von 312 KB auf 135.71 KB reduziert (G41), Lighthouse Performance 100/100.
- **App-seitige Authentifizierung (G42):** Entkoppelte `AuthAdapter`-Architektur, `<ProtectedRoute>`, Login-Seite mit Demo-Hinweis, Playwright-Auth-State (`globalSetup`), 165/165 Playwright-Tests grün.
