# Release Notes v2.3.2 — LeadPilot Dashboard-CRM

**Version:** `2.3.2` · **Lizenz:** proprietär, **All Rights Reserved** ([LICENSE](../../LICENSE))
**Status:** veröffentlicht am 27.09.2026 (G67 freigegeben von Codex, Sichtprüfung G67-9 bestanden, Release-Freigabe Marc Pönisch; annotierter Tag `v2.3.2` auf dem signierten Merge-Commit `9372b43` von PR #37).

> **Hinweis zum getaggten Stand:** Die Fassung dieser Datei im Tag `v2.3.2` stammt von vor dem Tag und nennt noch den Status „Release-Kandidat“. Maßgeblich sind diese Fassung auf `main` und das GitHub-Release „LeadPilot v2.3.2“. Der Tag wird dafür nicht verschoben.

v2.3.2 stellt das Aussehen der 32 statischen Inhaltsseiten aus v2.2.0 wieder her
(Auftrag 069, Gate G67). Keine Änderung an Daten, Simulation, Auth oder Schema.

## Behoben

- **32 Inhaltsseiten sehen wieder aus wie vor v2.3.0.** v2.3.1 hatte versucht, die Seiten in HTML
  nachzubauen; Schriftgrößen, Kopfbereich, Diagramme und Texte wichen sichtbar ab. Jetzt zeigen
  die Seiten wieder die Original-Bilder aus v2.2.0, bitgenau unverändert. Der Bildvergleich gegen
  v2.2.0 ergibt auf 1440 und 768 px 0,000 % abweichende Pixel.
- **Handy:** Immer das ganze Bild in voller Breite. Im Querformat ist es direkt gut lesbar. Im
  Hochformat steht darüber ein Hinweis: Handy quer drehen oder mit zwei Fingern zoomen.
  Kein seitliches Scrollen.
- **Barrierefreiheit bleibt:** Unter dem Bild liegt der Seiteninhalt als unsichtbare Textschicht
  (genau eine Überschrift, Tabellen, Listen, Diagramm-Zusammenfassungen) für Screenreader und Suche.

## Rückweg zu v2.3.1

- **Schalter:** `src/config/pagePresentation.ts`, `PAGE_PRESENTATION = 'html'` stellt das Aussehen
  von v2.3.1 wieder her. Die v2.3.1-Seiten sind unverändert im Code.
- **Tag:** `v2.3.1` zeigt weiter auf `1bbe32d` und kann jederzeit ausgeliefert werden.

## Nicht betroffen

Executive Dashboard, Live-Simulation, Leads, Accounts, Deal-Pipeline, Aktivitäten, Datenbasis,
Standort, Sidebar und Logo.

## Neu für Entwickler

- `src/components/imagePage/` (Bildseite, Zuordnung Seite → Bild) und
  `src/config/pagePresentation.ts` (Schalter).
- Test `src/app/__tests__/g67ImagePages.ui.vitest.tsx` (Bild, Hochformat-Hinweis, Textschicht, beide

## Upgrade von v2.3.1

Nur Frontend: neu bauen und ausrollen. Keine Migration, keine Secrets, keine Functions.
